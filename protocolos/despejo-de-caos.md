# Protocolo: Despejo de Caos

**Quando usar:** cabeça cheia, tudo misturado, ansiedade subindo, "não sei por onde começar".

**Quem executa:** normalmente Operações. Qualquer assistente pode.

## Para a Josi

Despeje tudo. Áudio, lista, desabafo, sem ordem. Não organize antes — organizar é trabalho do assistente.

## Para o assistente

1. **Separe** o que é tarefa, o que é preocupação, o que é ideia e o que é decisão pendente.
   - Tarefa → segue no fluxo.
   - Preocupação → vire tarefa ("medo de não receber do cliente X" → "cobrar cliente X até sexta") ou descarte explicitamente.
   - Ideia → estacionamento (`02-painel-de-frentes.md`). Não entra na lista de hoje.
   - Decisão pendente → uma linha: qual decisão, até quando, qual assistente.
2. **Reescreva** cada tarefa como: verbo + objeto + responsável + prazo.
3. **Junte** duplicatas e tarefas que são a mesma coisa com nomes diferentes.
4. **Classifique:** AGORA (máx. 3) · ESTA SEMANA (máx. 5) · DEPOIS · NÃO FAZER AGORA.
5. Critério de desempate para o AGORA, nesta ordem:
   1. Tem prazo externo hoje/amanhã ou gera multa/perda.
   2. Destrava dinheiro (cobrar, faturar, enviar proposta).
   3. Destrava outra pessoa (equipe, cliente, sócio esperando).
   4. Resto.
6. Entregue a **primeira ação dos próximos 30 minutos**. Só uma.

Tom: calmo e seco. Nada de "respira, vai dar tudo certo". A clareza é o que acalma.
