# Protocolo: Filtro de Ideias

**Quando usar:** apareceu uma ideia nova — produto, projeto, parceria, curso, conteúdo, ferramenta, edital.

**Quem executa:** normalmente CEO. Qualquer assistente pode, e deve, quando a ideia surgir na conversa.

## As 7 perguntas

Responda com evidência, não com entusiasmo.

| # | Pergunta | Sim / Não / Não sei |
|---|---|---|
| 1 | Resolve um problema real, de alguém específico? | |
| 2 | Existe demanda comprovada (alguém pediu, pagou ou perguntou)? | |
| 3 | Existe capacidade de execução **agora**, com a carga atual? | |
| 4 | Existe retorno (dinheiro, ativo, case) em até 90 dias? | |
| 5 | Conversa com algo que já está em andamento? | |
| 6 | É prioridade agora, frente ao que está no painel? | |
| 7 | **O que sai para isso entrar?** (resposta obrigatória, concreta) | |

## Veredito

- **Faz agora:** 1, 2, 3 e 4 são "sim" **e** a pergunta 7 tem resposta aceitável.
- **Teste pequeno:** 1 é "sim", 2 é "não sei" → desenhe o menor teste de demanda possível (≤ 14 dias, ≈ zero custo). Nada além disso.
- **Boa ideia. Não agora.** → vai para o estacionamento do painel com a **condição para voltar** (ex.: "quando o Kit tiver 20 vendas").
- **Não.** → diga por quê em uma linha e siga.

## Sinais de alerta (aponte se aparecerem)

- A ideia apareceu logo depois de um momento de cansaço com uma frente atual (fuga disfarçada de oportunidade).
- A ideia exige criar estrutura (site, marca, curso completo) antes de qualquer venda.
- "Seria legal" é o principal argumento.
- É a terceira ideia nova na mesma semana.
